# 公司主板接入入口

将 `mcu_rsp.h/.c` 加入主板C工程。参考只依赖stdint/stddef/string，不依赖W803、FreeRTOS或雷达SDK。

1. 提供新的非0 64位token回调，跨重连/主板重启不复用；不是固定种子或uptime。
2. UART字节由单一任务调用 `mcu_rsp_feed()`，定期调用 `mcu_rsp_poll()`，将返回的完整帧交给串口；发送不完整时调用disconnect，不能丢掉后继续推进事务。
3. 默认自动IDENTITY→CAPS→OPEN→每2秒SNAPSHOT，只读取，不自动开始监护。READY后业务层调用 `mcu_rsp_begin()` 发送0120 START；其应答可能PENDING，再读0122确认最终状态与monitoring=1。
4. STOP用0121，发出即清本地旧结果；收到monitoring=0/控制失败时也清数值。错误7/超时必须检查实际保存/控制状态，不能直接换新编号重做有副作用业务。
5. `mcu_rsp_result()`给出72字节快照副本并增加年龄，6秒无新快照返回0。保活和事件不会刷新这个时间。接收缓存回复时保守增加整个事务耗时，避免旧测量“变年轻”。
6. `mcu_rsp_reply()`取得业务应答数据与错误码；配置、安装读回、事件分页及统计按D0.7字段表解析。确认事件只代表收到，不清当前告警。自动结果轮询与业务请求共用单待应答事务，pending时begin返回0，待完成后再提交。
7. 主板自己的显示、存储、联网和通知策略在业务层；不把候选/保持/未知/谐波冲突当独立新测量，也不把无可靠呼吸估计解释为呼吸暂停。

物理层：主板TX→模块六针RX/J1.5/PB7，主板RX←六针TX/J1.2/PB6，共地，115200、8N1、3.3V逻辑。02组是调试/烧录口。主板具体型号及电平转换由主板团队按硬件落实，本参考未烧入未知型号主板。

完整命令、布局、单位、错误与状态转换见同级上一层 `协议D0.7_双芯片产品接口.md`。黄金帧与软件往返结果为模拟数据，不是人体或现场串口记录。
