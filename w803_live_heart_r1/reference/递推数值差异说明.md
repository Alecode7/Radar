# 双精度频率递推试验结果与默认路径选择

2026-11-18。按建议实现真实时间戳上的频率方向递推，全部double、每16频点重锚，保持原145点网格与每频点内累加顺序。无单精度、无阈值修改。

## 结果

21个回放用例共2687个对照时刻，覆盖实录、边界与连续生成的30分钟模型。部分用例共享数据、采用不同口径回放，不能当作2687个独立人体实验。基线是冻结C1共享double内核，本次没有声称重新全部运行原Python。

新代码的原直接路径与C1完整56字节结果逐字节相同。递推路径功率误差虽小，仍出现60个离散差异时刻，原判定等价验收不通过。因此C2默认DIRECT，递推是显式试验模式。

本轮1781帧在72个时刻中有7次离散差异：4次有值/无值不同；双方都有值时最大差7次/分钟。源MS157553原版等待确认，递推提前接受56；源MS177594原版新接受63，递推保留56。随后平滑历史和接受时间也会变化。两路本轮新接受总数均为13，并不意味着接受时刻或结果一致。

5组非均匀时间向量、80/151/160/300/416样本的实际频谱核探针，按最大参考功率归一的最大绝对误差约2.3e-14。这个口径不是每个频点各自相对误差的保证。它说明频谱接近，却不能证明带去重、比较边界与确认历史的输出等价。尚未逐语句证明每个最早分支翻转的唯一来源，不能用“double误差小”跳过结果验证。

## 保留了什么

原质量门槛、运动判断、呼吸谐波判断、候选确认、保持、平滑、频点及时间窗没有人为调整。改变的是三角函数生成方式，浮点结果可能变化并经状态历史放大。C2保留原直接模式为默认；`link compare`仅在冻结副本上运行另一模式，不发布该模式结果；`link spectrum rotate16`才显式切换活动模式并重新积累数学历史。

## 尚不能下的结论

- 87000→6600是300样本DFT部分的三角函数调用统计，不是整机提速倍率。
- 原直接路径对照相同，不等于过载合并请求时仍完成了原来的全部5秒估计序列。
- 递推更早出值或新接受总数相同，都不能证明更准；没有同期连续参考心率。
- C2尚未上板测速度、任务并行与稳定性；通常3秒、压力不超过5秒仍是待验工程目标。

详细逐项结果在evaluation/*.json，汇总在spectrum-verification.json；该对照脚本存在离散差异时故意非零退出。
